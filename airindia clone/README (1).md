# Nimbus Air - Airline Homepage

A homepage for a fictional airline, built with HTML and CSS only.
"Nimbus Air" is not a real company; the logo, text and offers are all original.

## Sections
- Top strip and sticky navigation bar
- Hero banner with flight search box
- Quick links (Web Check-in, Flight Status, etc.)
- Special Offers
- Popular Destinations
- Services
- Footer

## How to run
1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation needed.

## Files
- `index.html` - page structure and content
- `style.css` - styling (responsive for mobile)
