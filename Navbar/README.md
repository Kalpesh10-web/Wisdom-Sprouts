# Navbar Assignment (HTML and CSS)

Five navigation bar / footer layouts, each in one self-contained HTML file
(the CSS is inside the file, so nothing else is needed to run it).

| File | What it is |
|------|------------|
| `1-chat-navbar.html` | Chat app header with group name, buttons and icons |
| `2-network-navbar.html` | Professional network navbar with search and badges |
| `3-ticket-navbar.html` | Ticket booking navbar with two rows |
| `4-institute-navbar.html` | Training institute navbar with contact button |
| `5-social-footer.html` | Social media footer with links and language |

All brand names and logos are original or fictional (SnapShare, TicketTown, Green Shoots, etc.).

## How to run
Open `index.html` in any browser and click a link, or open any file directly.
